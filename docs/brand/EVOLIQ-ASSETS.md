# EVOLIQ corporate branding

The application and its README use original EVOLIQ corporate artwork, supplied
by the owner's existing company projects. The horizontal black/white PNGs are
copied unchanged from the EVOLIQ OnePaper application's `evoliq_logo.png` and
`evoliq_logo_white.png`. Their corporate mark matches the EVOLIQ website branding.
The website project was also inspected for its light/dark variants.

The app selects the black mark on light backgrounds and the white mark on dark
backgrounds. The logo links to the corresponding English/Slovak EVOLIQ website
in a new tab, preserving the current conversion screen. It appears in the footer
on every screen, the authenticated desktop header, and the About section.
